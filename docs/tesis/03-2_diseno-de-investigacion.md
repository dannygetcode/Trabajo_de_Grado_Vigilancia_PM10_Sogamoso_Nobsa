## 3.2 Diseño de Investigación

El diseño es no experimental y longitudinal retrospectivo en lo que respecta a los datos. Se trabaja con series históricas y no se manipula ninguna variable ambiental. El software se desarrolla con un proceso iterativo e incremental guiado por Scrum. El componente de aprendizaje automático sigue las fases de CRISP-DM, y esas fases se ejecutan dentro de los sprints. Para verificar el sistema se usa un entorno que reproduce los datos históricos con un simulador de estaciones, el cual tiene reloj virtual y permite inyectar fallas de forma controlada.
